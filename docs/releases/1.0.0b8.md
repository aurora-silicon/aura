# Aura 1.0.0b8

Released from `main` 93c59a50. Changes since 1.0.0b7 (78bac92d):

- **Every T8132 Mac boots from its own disk (#104).** The four storage and memory steps that ran only on the J713 (the 13-inch M4 Air) now run on every T8132 board, so U-Boot can read the internal disk on the J604, J623, J624, J715 and J773g. Their device trees carry the aliases these steps use. The J713's display, ISP, GPU, AOP, USB3 and PCIe radio handoffs stay J713-only; on the other boards those devices stay off and the boot continues. Nothing changes on other SoCs.

The 1.0.0b7 notes, including the requirements for the CTXR window path on M4 and later, apply unchanged.

## Qualification

- CI build (gcc), stage1-clang, format-check and pytest are green on #104's head (da015e02).
- Not yet booted on the J604, J623, J624, J715 or J773g.
