# Aura 1.0.0b13

Released from `main`. Changes since 1.0.0b12 (ea20cedb). It also carries the 1.0.0b12.1 changes (#195, #197, #200), which were merged to `main` as well.

- **DART tunables (#208).** aura copies each `/arm-io/dart-*` ADT node's `dart-tunables-instance-N` values to the enabled device tree DART at the same physical address, as `apple,tunable` triples. A DART that already has the property keeps it. More DARTs now start with the settings iBoot gives them: 5 to 31 on the M1 Pro, 4 to 25 on the M2, 3 to 24 on the M4 Pro and 25 of 29 on the MacBook Neo, with both video encoder DARTs among them.
- **MacBook Neo (T8140) GPU firmware data (#204).** `/reserved-memory/gpu-fw-data` is filled with the span of both GPU firmware roles' `__DATA` (ADT `gfx-data` and `gfx1-data`) when the device tree has the node, as on T6040 and T6050, so the kernel can map the crash log the firmware points at.
- **MTE tag storage (#184).** On SoCs with MTE2, the MTE tag store is reserved, or MTE is turned off, before Linux gets the memory map. Before this the tag store was handed over as normal RAM.
- **USB shutdown (#196).** DWC3 shutdown retires active transfers before it releases their memory. When a controller cannot be stopped, its memory is reserved in the device tree and the boot goes on.
- **Stage 1 layout (#202).** `aura-raw.ld` starts `.text` right after `.init` in the same read-execute segment, instead of on the next 64 KiB step. Every function is unchanged. A default Stage 1 has 10 to 18 KiB of room left, depending on the toolchain, instead of 96 B to 6 KiB. `stage1_size.sh` fails under 4 KiB and warns under 8 KiB.
- **M4 (T8132) video encoder (#152).** The encoder gets its preloaded firmware handed over as on the M4 Pro and A18 Pro.
- **M4 Pro / M4 Max (T6041) second external display processor (#166).** dcpext2 firmware memory is handed over when the device tree describes `/dcp@606e00000`.
- **MacBook Air M5 (T8142) on macOS 27.2 (#192)** and **Mac mini M6 (T8152) on macOS 27.2 (#189).** GPU firmware TEXT and the 26B123 firmware builds are accepted.
- **Mac mini debug port (#176).** The boot console warns when a USB host is on a port other than the debug port.
- **Tools and docs.** `proxyclient/chainload.py --stub` takes a prebuilt copy stub (#186). The README builds with `gmake` on macOS (#170).

The 1.0.0b7 notes on the CTXR window apply unchanged.
