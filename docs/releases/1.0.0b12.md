# Aura 1.0.0b12

Released from `main`. Changes since 1.0.0b11 (eca16db0).

- **MacBook Neo (T8140) video encoder 0 (#190).** The encoder enable walked the power-domain providers above the encoder and its DARTs only six levels up. Device trees that describe the T8140 fabric power states (linux 050f6a51 and later) put encoder 0's me1 state eight levels below the top of its chain, so 1.0.0b11 left encoder 0 disabled on those trees and the Mac had no video encode. Every chain is now walked to its top, a cycle is refused as soon as it appears, a 32-level bound stops a broken tree, and each refusal is logged with node names. Encoder 1 (`ave1`) is unchanged.
- **M4 Pro (J616s) at EL2 (#148).** A fixed memory layout for hibernation (`hib=1`), the windows the T6040 suspend-to-RAM driver reads, the display handoff on a 26.7 machine, and a fix for the S2R wake path.
- **M4 MacBook Pro 14" (J604) AOP (#149).** The AOP is handed off as on the J713: AOP DART DAPF, firmware segments and windows, so the light sensor, lid angle, motion and board temperature services start.
- **J813 (#183).** Linux boots with `arm64.nomte` while the MTE tag store is not yet reserved.
- **Comments (#185).** A T6040 display-power comment no longer points at a note outside the tree.

The 1.0.0b7 notes, including the CTXR window requirements on M4 and later, apply unchanged.
