# Aura 1.0.0b6

Released from `main` 3616f9c8. Changes since 1.0.0b5 (9a173ff5):

- **Linux at EL2 inside the CTXR window on M4 and later (#77).** A Mach-O Stage 1 with a zero-size boot text (kcbz 0) skips SPTM, and iBoot then confines the secondary CPUs' EL2 instruction fetches to a window it sets up from the boot object. aura moves the kernel into that window, tells it the window in the device tree, and starts Linux at EL2 on every chip, as on M1 to M3. The EL2 monitor (Linux at EL1, PSCI), the NV2 host and PV-KVM are gone. Only CYC_OVRD is locked from M4 on, and aura never writes it there.
- **T6041 (M4 Max) (#67, #68, #71, #73).** Display handoff on J616C, GPU resources, the iBoot-loaded ISP firmware, and boot-core power gating.
- **T8142 (M5) (#79, #80, #83, and the J813 ISP series).** GPU handoff, the N1 Wi-Fi/Bluetooth PCIe link trained before Linux, a display segment iBoot leaves unmapped skipped, and the ISP heap path.
- **J713 ISP (#84).** The ISP firmware is handed over to the kernel.
- **J873 and J813 bring-up (#85, #87).** A guarded minimal Linux boot on J873, and guarded CDC uploads on J813 and J873.
- CI and policy: #69, #97.

## Requirements on M4 and later

The window path needs all of these together:

- a padded Mach-O Stage 1 that chainloads `m1n1/boot-ctxr.bin` (aurora-silicon/aurora-installer#104);
- a kernel built with `CONFIG_ARM64_CTXR_EXECMEM` (aurora-silicon/linux#985), which keeps every executable kernel page inside the window;
- a U-Boot with aurora-silicon/u-boot#32, which loads the kernel into the window. With an older U-Boot the kernel boots on the boot CPU alone and says why.

Distribution packages ship `share/aura/monitor-free` with this aura, so updates write `m1n1/boot-ctxr.bin` on Mach-O Macs and leave `m1n1/boot.bin` alone. Macs that enrolled an unpadded Mach-O Stage 1 keep booting their current `boot.bin`; reinstall to move them to this path. M1 to M3 boot as before.

## Qualification

- CI build, format-check, pytest (Ubuntu gcc and LLVM, arm64, macOS 15 and 26) and the clang Stage 1 link are green on #77's head.
- J700 (T8140): #77 at cda450d as Stage 2 behind the padded Stage 1, with U-Boot from #32 and a #985 kernel: 6 CPUs at EL2, no window violations, modules, BPF (test_bpf 1061/1061), kprobes and ftrace, KVM and s2idle all pass, and fetches outside the window fault on the secondaries.
