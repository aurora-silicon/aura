# Aura 1.0.0b5

Released from `main` 04b06cec. Changes since 1.0.0b4 (8b150963):

- **Speaker amps (#75).** kboot copies each SN012776 amp group's configuration from the ADT onto the amp nodes of the DT: `apple,bop-config`, `apple,amp-dcblocker-config` (group-wide), and each amp's own `apple,speaker-config` and `apple,amp-tx-zd-config` rows. A property the ADT lacks, or a row table that does not cover every amp, is not passed on.
- **J713 external displays (#74).** The external DCPs are handed over to the kernel.
- **J614s Stage 2 handoffs (#72, #45, #46).** michal's merge train: HDMI PHY tunables, AOP/ISP, SEP and live ANS SART reservations, DAPF via the T6040 discovery, root-device address, and CPU cooling maps that no longer stop the boot when they cannot be pruned.
- **Debug UART (#65).** The debug UART stays the OS console only on debug boots.

## Kernel requirement

Kernels with aurora-silicon/linux #981 take the SN012776 amp levels, brownout, DC blocker and idle sense slots from these properties. Under an older aura those kernels keep the speakers off (fail-safe). Ship this aura (Stage 2, and Stage 1 where it boots the kernel directly) before such a kernel.

## Qualification

- Host tests: `tests/run-kboot-audio.sh` 9/9; CI build, format-check, test and release green on 04b06cec.
- M2 (J413) and M1 Pro (J316s): the 04b06cec tree as Stage 2 with the 7.1 DTB set and U-Boot unchanged, with a #981 kernel: every amp's properties byte-identical to the Mac's ADT (4/4 and 6/6 amps), speakers working with speaker protection active, 0 AVCs.
