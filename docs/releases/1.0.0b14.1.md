# Aura 1.0.0b14.1

A maintenance release of 1.0.0b14, from `release/1.0.0b14`. It adds one fix (#421).

- **Every M4 Max (T6041) reset at boot on 1.0.0b14 (#421).**
  - **The cause.** Since #320 a known MCC that fails to initialise is fatal on every chip. The firmware-cache path admitted `mcc,t6041` only with four AMCCs at fixed windows, which is the M4 Pro's layout. The M4 Max's ADT describes eight, and a binned part enables six of them with `amcc-enable-mask`. So every 1.0.0b14 stage, Stage 1 and Stage 2 alike, stopped at `MCC initialization failed` and reset the Mac.
  - **The fix.** `mcc_init_firmware_cache()` now takes everything from the ADT: the AMCC count, the AMCC and channel enable masks, the planes, the stride and the windows. It reads only the enabled AMCCs and checks each window against `/chosen/lock-regs/amcc`.
  - **When it leaves the MCC alone** (`MCC_UNSUPPORTED`, and the boot goes on): an ADT that leaves something out or contradicts itself, or a cache status other than the one iBoot leaves. In each case it touches no register, and the carveouts come from the ADT list as before.
  - `mcc_init()` no longer fails on ADT input. The other MCC drivers are unchanged.
- **Known issue in the 1.0.0b13.1 distribution packages built from 2f487f26** (Fedora `aura-1.0.0~b13.1-3`, Arch `1.0.0b13.1-4`, NixOS at 2f487f26). Their Stage 2 has the same reset on every M4 Max.
  - Where Stage 1 is 1.0.0b4 or later, the distributions' Stage 2 updaters install a new Stage 2 as an aura-try trial. The reset therefore costs one failed boot per update, and the Mac falls back to its working Stage 2. It stays there until it gets this release.
  - Where Stage 1 is older than 1.0.0b4, the updaters replace Stage 2 directly.

`VERSION` stays `1.0.0b14`, so the images are labelled `1.0.0b14-g<commit>`, as 1.0.0b13.1's were labelled `1.0.0b13-g<commit>`. The distributions' Stage 2 updaters parse the Stage 1 version as `<x.y.z>b<N>` with an optional `-g<commit>`. A `1.0.0b14.1` label would turn off their aura-try trials. Distribution packages carry the version 1.0.0b14.1.

The 1.0.0b14 notes, and the 1.0.0b7 notes on the CTXR window, apply unchanged.
