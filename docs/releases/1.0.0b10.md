# Aura 1.0.0b10

Released from `main` 8e043bc7. Changes since 1.0.0b9 (5211a863):

- **USB4 routers stay on with v2 routers (#103).** The root complex register of a `cio` node now comes from the router's ADT compatible (`acio` or `acio,v2`), so v2 routers (M4 Pro/Max, M5, M5 Pro/Max, M3 Ultra) are no longer disabled with their DART and NHI before Linux starts. Every v2 router takes the NHI tuning table without the per-direction `hi_up` entries. On the M2 (T8112), a PCIe-C DART whose ADT node has no tunables gets an empty `apple,tunable`, so the kernel cold-initializes the tunnel.
- **M4 DCP PIODMA gated on firmware 26.6.2 (#116).** PIODMA on M4 Macs follows the OS firmware version, not the J713's DCP image UUID, so the J604 and other M4 Macs on 26.6.2 get it too.
- **T6041 SIO boot tables (#120).** The M4 Pro/Max (T6040/T6041) SIO, which carries DisplayPort and HDMI audio, gets its boot tables in the layout its firmware expects: shim selectors only on the records the ADT describes, no loader-built response array, and tables placed on the first 16K page past the preloaded firmware segments. Other SoCs are unchanged.
- **Speaker assembly ID (#121).** When the ADT has `find-speaker-id`, aura reads the `function-speaker-id0/1` straps the way macOS does and passes the result to the kernel as `/chosen/asahi,speaker-id` (big-endian u32; 65535 for an ID not in `valid-speaker-ids`). Macs without the straps get no property. No user default changes.

The 1.0.0b7 notes, including the CTXR window requirements on M4 and later, apply unchanged.

## Qualification

- CI build (gcc), stage1-clang, format-check and pytest are green on the release head.
- aura-try Stage 2 trials of the release commit (build `dev-dcc3b2643dbc`) on the lab Macs. Each trial image is that Mac's committed Stage 2 with only the aura head replaced, booting the Mac's current kernel. Stage 1 was not touched, and every Mac went back to its committed Stage 2 afterwards.

| M1 Pro J316s | `m1n1/boot.bin` | 0 (macOS: 0) | Boots; 0 AVC; Wi-Fi, keyboard and Touch ID services up; one `pm_test=platform` suspend cycle (no RTC wake alarm on this Mac) |
