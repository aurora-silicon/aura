# Aura 1.0.0b11

Released from `main`. Changes since 1.0.0b10 (21a70e6e).

The distribution 1.0.0b10 packages were built from a later `main` commit (bd9f3e82) and already carry the changes in the first list. The second list is new for distribution users.

## Already in the distribution 1.0.0b10 packages (bd9f3e82)

- **Boot watchdogs.** Stage 1 keeps a watchdog armed over the plain boot path (#127). aura-try one-shot trials work for a `boot=` kernel too (#82).
- **Mach-O boot objects.** The payload scan stops at the boot object's `__PRELINK_INFO` (#134). A Recovery script enrolls a hand-built Stage 1 (#131).
- **PMP.** T6000 and T8112 PMP boot data is published without aliases (#88). Linux gets the PMP media performance requests from the ADT (#150).
- **USB gadget.** The high-speed DWC3 engine recovers from bus reset and disconnect (#130), and every no-data status stage waits for XferNotReady (#139).
- **M4.** The T6040 boot core can power-gate (#119). The J604 gets the MTP filter (#137) and the J715 and J604 the radio port (#141).
- **M2 (J613).** GPU powered identity and the external display handoff on 25G83 firmware (#86).
- **T8142 on macOS 27.0.** The ISP accepts the 27.0 firmware (#99), the secondaries' writable state stays out of CTRR_D (#100) and the GPU firmware data is reserved as fw-data (#143).
- **M5 Pro (T6050).** Linux boot path and the shared ANS handoff (#144). APCIe ANS recovery tables are published with an atomic packed-DT export (#112).
- **CI.** Stage 1 and the ESP Stage 2 are uploaded as separately named artifacts (#142).

## New in 1.0.0b11

- **Memory a device may still reach stays allocated (#175).** When a DART invalidation times out or an NVMe completion is lost, the domain is marked failed and the buffers, IOVAs and RTKit instances it may still reach are kept instead of freed. The proxy reports DART failures to the client.
- **DART (#180).** A Gen3 invalidation that does not finish within 1 ms marks the domain failed, as a busy timeout does on other generations. `dart_free_l2()` takes the L2 table from the root it was asked about, not root 0.
- **Watchdog reset before `wdt_disable()` (#138).** A fault taken before the watchdog is first looked up now resets the Mac instead of spinning on the boot logo.
- **Video encoder.** M1 Pro (T6000) and M2 (T8112) get their preloaded encoder firmware handed to Linux, with the AVE DART tables and the DAPF entry it needs (#161). The M5 Pro/Max (T6050) encoder gets its firmware too (#171). On T8140 (MacBook Neo, J700) the handoff matches each encoder node in the device tree to the encoder the ADT describes (`ave`, `ave0` or `ave1`), hands that one over with its DARTs and power states, and disables the other (#167).
- **ANE.** The ANE node is found by its compatible, not its path (#168). The T6050 ANE firmware preload is handed off (#169).
- **PMP.** The T6000 scaler and ProRes codec get their PMP performance requests from the ADT (#156).
- **MacBook Neo (T8140) SIO.** DisplayPort/HDMI audio for an external display uses the T6041 SIO boot tables (#122).
- **M4.** The M4 Max laptops (J614c, J616c) export their ATC tunables, so their USB-C ports run at USB 3 (#147). The Mac Studio M4 Max (J575c) gets its external display handed over without a panel (#160). The J604 gets the T8132 USB3 calibration (#154) and its camera (#155).
- **USB.** A disabled USB description no longer disables a PHY or DART that a live controller shares (#153).
- **M5 Pro (T6050).** External display DARTs are added to the display subsystem (#158), NVMe adopts a live session from an earlier stage (#159), the framebuffer is read uncached in a vectored Stage 2 (#179), and the remaining boot path fixes are in (#173). M5 Ultra multi-die groundwork: AIC IRQ numbers, CPU die, PMGR die stride and MIDR parts (#178).
- **Secure boot, off by default (#133).** Signed payloads (`aura_sig`), signed next stages (`AURSIGT1`), `SECBOOT=audit|enforce` builds and a measured-boot record in `/chosen/aurora,boot-security`. Release builds keep `SECBOOT` off; see `docs/secure-boot.md`.
- **Generic fixes and tools.** `dt_parse_ranges()` honours `#address-cells`/`#size-cells` and stops at the property end (#174). The proxy client waits up to 3 s for the first reply and drops stale replies at NOP (#162, #174). A J613 RTC alarm DTB preparation tool (#157). Comments describe hardware behaviour (#177).

The 1.0.0b7 notes, including the CTXR window requirements on M4 and later, apply unchanged.
