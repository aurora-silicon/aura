# Aura 1.0.0b17

Aura supplies both SIO boot table layouts on systems that use the low DMA window. Linux selects the layout that matches the protocol reported by SIO firmware, allowing the same boot payload to serve firmware that reports protocol 9 or 10. [Aura SIO change](https://github.com/aurora-silicon/aura/pull/495) · [Linux protocol selection](https://github.com/aurora-silicon/linux/pull/3051)

The protocol 9 path booted on the M2 Air and completed two short suspend and resume cycles. The protocol 10 path booted on the M2 mini, which opened and streamed to both display audio endpoints in the prior qualification with the matching kernel changes. Tagged builds and distro packages have their own qualification records. See the linked Aura change for the source and kernel combinations used.

A complete boot bundle needs matching DTBs and U-Boot. Use coordinated distribution packages when updating the boot bundle.
