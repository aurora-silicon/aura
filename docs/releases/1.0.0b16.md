# Aura 1.0.0b16

This release follows `main` at `8b1cb8ce` and updates the release version to `1.0.0b16`.

- On M2 systems, Aura hands the 27.2 G14G firmware state to Linux for GPU acceleration. This path keeps automatic GPU power-gating off. [GPU handoff](https://github.com/aurora-silicon/aura/pull/402)
- Aura exports both USB 2 device tunables together when it can validate the pair. [USB device tunables](https://github.com/aurora-silicon/aura/pull/376)

The Stage 2 source at `8b1cb8ce` booted the lab M2 Air, M2 mini, M1 Pro, and M4 Pro with fleet87. Those rows used the previous version label. Release builds and distro packages have their own qualification records.

The base M5 boot path also needs a matching U-Boot and kernel, and a refreshed installer payload. Check the versions in the signed distribution delivery before retrying an installation.
