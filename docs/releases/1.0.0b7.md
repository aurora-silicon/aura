# Aura 1.0.0b7

Released from `main` 6aad7fd1. Changes since 1.0.0b6 (21a8ab94):

- **Stage 1 links with clang 22 (#101).** 1.0.0b6's Stage 1 `.text` ended 2676 bytes past its 64 KiB step with clang 22, which NixOS builds aura with, so the image reached the DCP log buffer and the link stopped. The hypervisor's two largest objects now sit in the mostly empty `.init` slot, leaving `.text` 12.9 KiB under its step. Nothing else changes.

1.0.0b6 never shipped in a distribution; use this release instead. Its notes, including the requirements for the CTXR window path on M4 and later, apply unchanged.

## Qualification

- CI build (gcc), stage1-clang (clang 23), format-check and pytest are green on #101's head.
- clang 22.1.8 with lld, `RELEASE=1 CHAINLOADING=1 BUILTIN_LOGO=aurora USE_CLANG=1`: Stage 1 and the ESP Stage 2 both link; `_file_vital_end` is 0x11aa90 and 0x11a990, under the 0x120000 limit.
